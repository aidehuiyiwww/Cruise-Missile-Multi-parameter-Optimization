# Constrained-Flight-Vehicle-Multi-Parameter-Optimization
Cruise missile overall parameter optimization using interior penalty function, exterior penalty function, complex method, and random direction method to minimize take‑off mass.


## Overview
This project focuses on the **overall parameter optimization design of a cruise missile**. Based on trajectory modeling and mass modeling, we take **minimum take-off mass** as the optimization objective and apply four typical constrained optimization algorithms to solve the design problem. The optimized scheme reduces the take-off mass by about **10.9%** compared with the original reference scheme, which proves the effectiveness of the model and algorithms.

## Optimization Methods
1. Interior Penalty Function Method
2. Exterior Penalty Function Method
3. Complex Method
4. Random Direction Method

## Key Design Variables
- Booster separation velocity V₀
- Average thrust-weight ratio of booster Pmj
- 1st-stage thrust-weight ratio of main engine P₁
- 2nd-stage thrust-weight ratio of main engine P₂
- Wing loading P₀

## Main Results
- Original take-off mass: **2095.6 kg**
- Optimized take-off mass: **1866.72 kg**
- Mass reduction: **229 kg (10.9%)**
